## 出行路程册子（无地图 · v0.1.32 重构自「路书模式」）

**定位**：小册子负责「这趟怎么决定」（砍选项、排顺序、不翻车）；出行路程册子负责「这趟每天怎么走」——当用户明确要一份**多日行程路程册子**（逐日节点、里程耗时、沿途 POI、住宿）时启用，与小册子决策流互补、不互相替代。

> **地图附图已暂停（v0.1.32）**：原「路书模式」的地图附图（第三方真实底图）实测问题多、体验不稳定，自 v0.1.32 起**全面取消地图附图**，统一退回**纯文字 / 表格动线**（出发→到达 + 方式 + 里程 + 时长 + 费用 + 停留）。第三方地图服务待找到可靠做法后再评估集成；在此之前**绝不输出任何 SVG 假地图或外部地图组件**。节点不再要求经纬度，以「地名 + 地址 + 停留 + 备注」承载，导航交给用户手机地图 App。

> **v0.2.274 补充：路线形态图不等同于地图附图，两者判据不同**
>
> v0.1.32 禁的是「第三方底图」和「凭空画的假地图」两类，不是所有图形表达。新增的「路线形态」图属于第三类，判据如下：
>
> | 类别 | 判据 | 现状 |
> |---|---|---|
> | 第三方底图 / 地图组件 | 依赖 leaflet·高德·OSM 等外部瓦片或 JS | **仍禁**（联网依赖 + 零外链要求 + 审图号） |
> | SVG 假地图 | 形状是编的，省界/海岸线凭想象画 | **仍禁**（假数据比没图更糟） |
> | 路线形态图 | 横轴按**真实经纬度算出的直线里程**排节点，只画点与连线 | **允许**（`scripts/route_viz.py`） |
> | 线路形状图（v0.2.274） | 用**已收录的真实 GPS 轨迹**等比例投影画路形，非想象 | **允许**（同文件 `render_trace_svg`） |
>
> 三条纪律：① 坐标查不到就**不出图**，绝不拿同名地点凑数；② 只画轨迹与节点，**不画国界/省界/海岸线**，故不构成须审图的公开地图；③ 图内必须自标「示意用，不作导航」，实际里程以逐日表为准。
>
> 数据来源：城市级 `references/destinations.json`（300 条带坐标），景点级 `references/moto_places.json`（2514 条带坐标，须带 `--admin` 约束防同名跨省错配），线路轨迹 `references/moto_traces.json`（6 条精选线路的真实 GPS 轨迹，Douglas-Peucker 抽稀，v0.2.274 起由 `render_trace_svg` 消费；未收录的 19 条如实写 `coverage.matched`，不硬凑）。

**触发词（已并入主 description）**：路书、road trip、route book、itinerary、多日行程、行程单、路程册、行程规划、route planning、travel itinerary、multi-day trip、每日行程、行程路线、出行路程册子。

**与大技能的同一套纪律**：
- 零地图——交付物为纯 HTML/PDF 文字册子，无任何地图脚本 / 外部地图组件 / SVG 假地图；坐标类需求以文字动线表达。
- 可信度内核——POI / 住宿 / 餐饮标注来源（官方 / UGC / 估算），天气与路况标注「出发当天需复核」，与 `unknown` 灰灯口径一致，绝不编造营业状态。
- 零依赖——交付为 AI 直接产出的结构化文字册子（复用主技能 `render_compact.py` 的卡册版式与 FAB 交互），不引入新脚本。

### 出行路程册子工作流

**第 1 步：需求采集**（缺失最多追问 2 轮）
| 字段 | 说明 | 默认 |
|---|---|---|
| 起点 / 终点 | 出发地与目的地（目的地必填） | 用户所在城市 |
| 天数 | 总天数 | 建议 2-3 天 |
| 出行方式 | 自驾 / 摩托 / 骑行 / 徒步 / 房车 | 自驾 |
| 偏好 | 景点 / 美食 / 咖啡 / 摄影 | 不限 |
| 节奏 | 宽松 / 标准 / 紧凑 | 标准 |

**第 2 步：路线规划（按出行方式每日里程上限拆分）**

| 出行方式 | 宽松 km/天 | 标准 km/天 | 紧凑 km/天 |
|---|---|---|---|
| 自驾 | 200 | 350 | 500 |
| 摩托 | 150 | 250 | 350 |
| 骑行 | 40 | 60 | 80 |
| 徒步 | 10 | 15 | 20 |
| 房车 | 150 | 250 | 350 |

- 将总里程按上限拆成 N 天，每天起点 = 前一天终点，每天排 2-4 个途经点（景点/休息/餐饮/住宿）。
- 沿途 POI 推荐 2-3 个/天，标注建议停留时间；每天终点附 1-2 个住宿区域（类型 + 预算档），并标「出发前需确认营业状态」。
- 单日里程如需 > 上限，按大技能里程纪律评估拆 2 天（近郊往返例外）。

**第 3 步：生成路程册子**
直接产出「逐日路程表」——每天一张卡：序号 / 节点名 / 地址定位 / 到达方式 / 累计里程 / 停留 / 备注 / 当日里程合计 / 当日贴士。可套用主技能 `render_compact.py` 的紧凑卡册版式输出 HTML/PDF，亦可纯 Markdown 交付。示例逐日卡：

| # | 节点 | 地址 / 定位 | 到达 | 里程 | 停留 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 佛山·家（出发） | 佛山市禅城区 | — | 0 | — | 满油、检查胎压 |
| 2 | 广州·午餐补给 | 广州市天河区 | 自驾 | 25 | 1h | 高速服务区简餐 |
| 3 | 衡阳·住宿 | 衡阳市蒸湘区 | 自驾 | 405 | — | 提前订车位 |

> 不要求真实经纬度；地址用「市 / 区 / 地标」级即可，导航交由用户端地图 App。

**第 4 步：交付**
1. 文字摘要：每日概览 + 总里程 + 关键提示（节奏 / 禁摩 / 补给 / 天气）。
2. 路程册子文件：逐日节点卡 + 里程合计 + 贴士，纯文字 / 表格，无地图。
3. 使用建议：出发前检查项、天气提醒、注意事项（摩托禁高速 / 禁摩区等安全纪律照常生效）。

### 出行路程册子约束（安全 / 标准）

1. **路线安全**：摩托出行必须避开高速（中国高速禁摩）；标注已知禁摩区 / 限行区；山路标注难度与注意事项；每天驾驶 ≤ 8 小时，每 100km 或 50 分钟安排休息，避免夜间行车。
2. **零地图承诺**：本模式不输出任何地图附图（真实底图 / SVG 假地图 / 外部地图组件一律不出）；节点以地名 + 地址 + 备注承载，导航交由用户端地图 App。第三方地图服务作为未来候选评估中（待找到可靠做法后再集成），未集成前不引入。
3. **信息可信度**：POI / 住宿 / 餐饮标注来源与「出发前需确认」；天气路况标注「出发当天复核」，绝不编造。

> **与 `travel-planner-expert` 的关系**：经核查，原 `travel-planner-expert` 插件为 v0.1.24 过期副本，缺失攻略检索模式、链接断言纪律、§09 渲染修复、25 条 moto 库等关键能力，**无单独于本技能的独有能力**；其专家插件形态由内部知识库端知识库侧另行承载。原 `route-book-agent` 的唯一真实增量能力（逐日里程拆分的路程册子）已吸收进本技能的「出行路程册子」模式，其地图附图部分因体验问题自 v0.1.32 取消。
