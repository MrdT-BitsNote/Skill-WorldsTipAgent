## v0.1.2（2026-11-04）

「优化并完善数据」轮次。对两个线上数据集做**全维度体检**（不是只看夹具），按实测发现的数据缺口补齐能力。修 bug 直接改默认并做 A/B 归因，新增能力一律默认关闭。

**数据体检发现并修复的真实缺陷**
1. **`dims` 谎报 0 条**：`leisure` / `kids` 实际是 `{subcats:[...], list:[...]}` 的 dict，旧版只认 list，把全库 33975 条 POI 报成 0。改为 `dim_pois()` 统一取值，且显式跳过 `subcats`（分类统计不是 POI，混入会虚增计数——T10 首次实跑即抓到）。
2. **漏掉 `xiaocan` 维度**：schema 明写的 11816 条小吃/苍蝇馆 POI 完全没读；现纳入 7 维统计并可按 `--dims` 查询。
3. **`hotels` 混入非住宿 POI**：全库 12097 条里 262 条（2.2%）首段是餐饮/住宅等，如「宏豪浦江一号(陆家嘴店)」是餐饮却当酒店推。新增 `is_hotel()`，与 `is_food()` 对称。
4. **`hotels` 输出违反自身规范**：SKILL.md 承诺「每个推荐 POI 带 name/rating/avg/addr」，实现只给 5 个名字。改为完整 POI 对象。
5. **重复 POI**：全库 431 条同城同维度同名（223/389 城），现按 `(name, addr)` 去重。
6. **`xiaocan` 自带「仅登记不推荐」标记**：2024 条被数据方明确标注不推荐，直接推给用户会违背口径；加 `NO_RECOMMEND_RE` 闸门并配**反向用例**（关掉闸门后脏 POI 确实漏出，证明过滤不是死代码）。
7. **缓存永不刷新**：`_load` 命中即返回，无 TTL / ETag / 刷新入口；线上更新后技能永远读旧数据。新增 `--refresh` 强制回源（离线模式下仍只读缓存，绝不偷偷联网），`stats` 报缓存清单与数据日期。

**新增能力（默认关闭 / 显式参数）**
- `rank` 命令：`food_top` 全国美食榜（800 条，按 `is_food` 清洗后 785）与 `districts_top` S/A 商圈榜（703 条）；支持 `--kind` / `--name` / `--rank-province` / `--n`。
- `city` / `cascade --dims`：按需返回 `malls` / `specialties` / `leisure` / `kids` / `xiaocan` / `hotels` 的清洗后 TOP POI；`--top` 控制条数（1..20）。
- `--detail`：附行政区构成、可信度、商圈评分摘要。
- `--with-track`：附 GCJ-02 轨迹 `p`、途经点坐标 `w`、路线配色 `c`（1713 条路线 100% 具备；默认关闭避免输出膨胀）。
- `cascade` 的途经点补 `coord`（与 `wn` 一一对应），去掉逐点重复的 `city_food_hint`，顶层只给一次 `food_hint`。
- `route.py` 补 `rank` 意图映射（「全国美食榜」「商圈排行榜」优先于 fun 关键词），数据纪律补酒店清洗与小吃不推荐闸门。

**回归证据（R4：同输入 A/B，不换统计口径）**
- 10 个默认路径跑 v0.1.1 zip 内脚本 vs v0.1.2：`routes` / `top-cities` / `route(default)` **逐字节零回归**；其余 7 个路径共 282 条差异，全部归入 4 类（dims 修正 54 / hotels 175 / POI 去重与 sub 字段 25 / 途经点坐标 28），**未解释项 0**。
- 真实全库重统计：7 维原始 **119219** 条 → 清洗后 **116155** 条（剔除 3064：food 777 非餐饮 / xiaocan 2024 不推荐 / hotels 262 非住宿 / malls 1 重复）。
- 10 套件 **204 断言**，新增 T10 全套 44 条覆盖全维度能力；夹具重写为复刻真实 `list` / `dict` 双形态。

## v0.1.1（2026-11-04）

四标准自检（`Skill 优化大师` / `SKILL产品经理` / `大厂标准` / `Skill 经验蒸馏`）后的改进版。**修真实缺陷，不放宽判据**。

**修复的静默类缺陷（均由实跑发现）**
1. **靠省份名前缀猜环线** → 改为只认 `citySlug=loops` 派生的显式 `is_loop` 信号。旧版把 `北京 / 上海 / 天津 / 吉林` 四条真实非环线路线误判省级，`cmd_city` 因此明明有档案却回报「无单城档案」。
2. **跨省子串假匹配**：`海南` 静默挂到青海「海南藏族自治州」并冒充 `normalized`。子串兜底加同省硬闸；不带省份且属跨省简称时列候选（先查后问）。全量 29 个子串命中里 28 个同省正确，仅此 1 例跨省。
3. **触发词与路由规则不对齐**：`description` 明写的「环青海湖住宿」被路由到 `city`、「fun 城市档案」到 `routes`，`stats` 意图是死代码。补 `stats` / 城市档案分支、环线口语识别（`环 X 湖/线/山/岛/江/河/城`，不裸用「环」字），13 条触发词回归。

**新增能力（默认关闭，保留退路）**

- 数据日期改为「读数据集 `generated`，不写死」；降级链描述对齐 `data-quality.md` §3。
- frontmatter 补 `agent_created: true` 与 `disable-model-invocation: false`；新增 `growth_log.md` + `references/insights.md`（12 条生效规则 + 8 条反模式）。
- T8 补版本四处一致 / `agent_created` / 进化引擎断言；新增 T9 套件覆盖路由与修复回归。

## v0.1.0（2026-11-04）

首个可用版本。把 moto.worldstip.com 骑行路线数据与 fun.worldstip.com 城市生活数据整合为单一技能。

**新增能力**
- `scripts/motofun.py`：6 个查询动作（stats / routes / city / cascade / top-cities / route），纯标准库零依赖。
- `scripts/route.py`：意图路由入口，产出动作链 + 该读文档 + 数据纪律清单。
- `references/api-spec.md`：两端字段口径（实测核验，非文档推测）。
- `references/data-quality.md`：脏数据统计、城市匹配率、分级降级规则、已知缺口。
- `test/run_all.py`：8 套件 118 断言边界验证集；`fixtures/` 手写规范夹具。

**数据修正（相对上一轮原型）**
1. `food[]` 混入非餐饮 POI → 按 `type` 首段 == `餐饮服务` 清洗（实测剔除 164 住宿 / 290 购物 / 157 休闲等）。原型曾把「瑞高酒店」当美食 TOP1。
2. 城市名后缀不一致（moto `常德` / fun `常德市`）→ 基名等价匹配。
3. 原型把 `wn` 途经景点名当城市名逐个查 fun 库 → 改为只用 `city` 字段联动，`wn` 作为景点展示。
4. 长途环线 `citySlug=loops` 的 `city` 是省名 → 识别后走省级汇总，不做单城联动，标注「非实测」。
5. 重庆 22 区县 / 4 个县级市无单城档案 → 显式降级（municipality / alias）并标注精度。
6. 不可信输入 → 受控错误码，无裸 traceback；输出确定性、幂等。

**回归发现并修复的缺陷**
- 初版歧义预扫描用宽松子串，把 `鞍山` 误判为歧义（子串命中 `马鞍山市`）。真实数据 386 名回归中歧义数由 0 变 1。改为「基名完全等价」判定后归零，用例固化进 T3。

**回归基线对比**
- 原型基线：386 名 → 333 匹配 / 0 歧义 / 53 未匹配。
- v0.1.0：`city` 路径 337 匹配 / 0 歧义 / 49 未匹配；`cascade` 路径 356 匹配 / 0 歧义 / 0 未匹配 / 30 省级。提升来自显式降级且逐条标注精度，非放宽判据。

**环境适配**
- Windows 沙箱在临时解压目录偶发 `CreateProcess` 权限拒绝（WinError 5）。验证集与打包器仅对该异常做最多 3 次受控重试，如实打印次数，用尽即判失败；不吞其他异常、不放宽断言。本地直跑 3 次零重试全绿。
