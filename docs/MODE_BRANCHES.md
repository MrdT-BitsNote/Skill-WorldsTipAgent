### ③-2 出行模式分支纪律（v0.1.16 新增 · 硬性）

**默认模式 = 公共交通**，除非用户明确指定出行方式。分支判定规则：

**-1. 出行陪伴结构（Party Type · v0.1.24 新增 · 四轴正交）**：每个请求先判「谁和谁同行」——`solo` 个人 / `couple` 情侣夫妻 / `friends-small` 结伴好友(2-4熟人) / `friends-large` 多人好友(≥5熟人) / `family` 家庭(跨代亲属含娃/老人) / `group` 团体(团建/研学/夕阳红等有组织方)。判据与优先级见 `CONTEXT.md` 与 `references/party_playbooks.json`。命中后经 `resolve_party_type()` 驱动三处：**分房口径**（情侣合住大床、同性好友拼双床、异性分房、家庭亲子/带长辈、团体组织者统订标间——`stay_plan()` 已内建）、**预算分摊口径**（solo 独担 / couple·family 合付 / friends AA / group 统付或包价，整团与人均两档都显式）、**安全与节奏侧重**（solo 报平安、friends-large 集合点、family 防走失午休、group 点名与走散预案）。**正交铁律**：Party 只定分房/分摊/安全口径，不改 audience（性别·带娃·年龄视角）、style（玩法强度）、theme（主题选点）三轴；`--party` 可显式覆盖（如 2 人团建应判 group）。未显式指定则自动推断并在报告标注「陪伴结构按 XX 推断，如不符可更正」。

**0. 主题玩法叠加（v0.1.17 新增）**：命中主题触发词（亲子研学 / 摄影旅拍 / 美食朝圣 / 温泉康养等）时，读取 `references/theme_playbooks.json` 对应 theme 块，**只叠加、不改骨架**：用其 `spot_criteria` 调整选点、`pacing` 调整节奏、注入 `gear_focus`、把 `pitfalls` 写进「避雷 / 落地提示」、`booking` 并入行前清单倒排时间线；并复用已有 `photography_guide` / `food_guide` / `audience_profiles` 数据（不重复造）。多主题命中以用户首要意图为主。红线：主题不改可信度内核，票价/花期/雪期/营业等 volatile 仍强制核验、查不到挂灰灯，绝不因主题编造推荐。

**1. 摩托出行**
- **触发词**：摩托、摩托出行、机车、摩旅、摩旅出行 → 按摩托车规划
- **长途 vs 短途**：以**是否跨市区**为判据
  - **短途（不跨市区）**：参考 `references/moto_routes.json` 的 `near` 近郊跑山线路（外部地图数据源「WorldsTip 摩旅地图库」已收录 31 省 1658 条线路，本省覆盖数见 `references/moto_coverage.json`），单程 60-150km，给路线 + 里程 + 补给密度 + 绿荫等级
    - **无明确目的地** → 根据用户所在地，从 `near` 线路库中推荐适合当季/当周的 2-3 条线路，附季节窗口与难度分级
    - **有明确目的地** → 按 `near` 线路匹配或规划新线路，输出：路线走向 → 逐段里程 → 补给点 → 绿荫等级 → 沿途美景穿插
  - **长途（跨市区）**：按各省禁摩政策（`references/moto_rules.json`）逐省判定——
    - 该省允许摩托上高速 → 可规划高速
    - 该省禁止摩托上高速 → 规划**国道/省道**（地图服务策略=6 不走高速）
    - 途经禁摩城市 → 标注绕行方案
  - **精选长途线路**：`moto_routes.json` 还提供 `long`（8 条长途穿越）与 `loop`（5 条环线）线路，带季节窗口/补给密度/高速依赖度/绿荫等级，长途规划时优先参考；其中部分线路（标注 `source: WorldsTip 摩旅地图库 / map-data`）由该地图库策展而来，完整 GPS 轨迹与 22 省全域可视化在该站内查阅
- **日行程规划**：
  - 理论极限 500km/天，**默认按 300km/天**规划（除非用户明确要求更多）
  - 注：300km 略超 `vehicle_range.json` 的机械安全极限（250cc 满油 400km × 0.7 安全系数 = 280km），实际需中途加油 1 次；用户要求时可达 500km（需加油 2 次）
  - **跨天行程**（单日 >300km 或多日出行）才安排住宿
  - 不跑高速时（走国道/省道），**尽量规划沿途美景**——从 `moto_routes.json` 途经点的名称/描述中识别山/湖/桥/古镇/观景台等，穿插进行程
- 摩托出行不考虑公共交通接驳——用户有交通工具

**2. 自驾出行（一般自驾）**
- **触发词**：自驾游、自驾出行、开车去 → 按小汽车/SUV/越野车/电车/混动等规划
- **日行程规划**：
  - 高速为主：**400-600km/天**（服务区密集，续航不是瓶颈）
  - 国道/省道为主：**250-400km/天**（沿途可穿插美景）
  - 参考 `vehicle_range.json` 查车型实际续航，剩余 < min_reserve 时必须补给
- **美景穿插**：不赶时间时（国道/省道），从 `moto_routes.json` 途经点中识别沿途山/湖/桥/古镇/观景台/梯田/瀑布等，穿插进行程
- **住宿触发**：跨天行程或多日出行才安排住宿；当天往返的近程自驾不硬塞住宿
- **电车/混动特别注意**：
  - 纯电：提前确认沿途充电桩分布（`vehicle_range.json` 的 `ev_charger_max_gap_km`），偏远地区充电桩间距可达 300km
  - 插混：短途用电、长途用油，关注是否有充电条件（酒店/营地/服务区）
- 自驾出行不考虑公共交通接驳——用户有交通工具

**2b. 房车出行（自驾的子模式，用户明确说「房车」时触发）**
- **触发词**：房车、房车出行、房车自驾、campervan → 从一般自驾切换为房车模式
- **五项后勤自检**（`scripts/rv_check.py`，与摩旅五项门禁同构）：
  - **驾照牌照**：蓝牌 C1 可驾 / 黄牌需 B-A / 拖挂需 C6（唯一可判红灯：持 C1 开黄牌或拖挂无 C6 = 违法上路）
  - **限高**：净高标准 + 房车车高区间；可避开→黄灯，绝不红灯
  - **补给半径**：按 `rv_logistics.json` 的水（85L/人·天）、电（基础 2-3 度/天，开空调 8-15 度/天）、油耗、LPG 计算补给节奏；水撑不过行程天数→黄灯
  - **黑水灰水**：房车默认黄灯提醒排污设施稀缺；已确认排污计划→绿灯；非房车→灰灯不适用
  - **营地过夜**：未订→黄灯（旺季强调爆满）；已订→绿灯
- **路线规划纪律**：
  - **营地为节点**：先确定营地位置，再规划日间路线（与摩托/一般自驾的「目的地为节点」相反）
  - **日行 200-350km**：房车速度慢、找营地/补水/排污耗时，日行程比一般自驾压缩 30-40%
  - **限高避开**：路线规划必须考虑沿途限高（隧道/立交/乡间限高杆），`restrictions.json` 查限高数据
  - **终点停靠**：只收官方正规设施（有设施≠能过夜、免费野营点不入库），证据优先（`rv_logistics.json` 的 `official_facilities`）
- **房车续航**：按 `vehicle_range.json` 的 rv 条目（油箱 80L / 油耗 13L/100km / 续航约 600km），另需关注生活用水/电/排污的「后勤续航」
- 参考数据：`references/rv_logistics.json`（后勤全参数）+ `references/vehicle_range.json`（续航）+ `references/restrictions.json`（限高/限行）

**3. 骑行 / 徒步**
- **触发词**：骑行、骑车、徒步、走路、登山 → 按对应方式规划
- **日行程基准**（`build_itinerary.py` 的 ACTIVE_ADDON）：
  - **骑行**：25-45km/天（视体力与路况）
  - **徒步**：12-22km/天（视海拔与负重）
- **必须包含**：
  - 怎么去（起点交通：怎么到达徒步/骑行起点）
  - 怎么回（终点交通：结束后怎么返回）
  - 路段距离与补给点（每段多长、中间有无补给）
  - 物资准备清单（装备、食物、水、应急物品是否完备充足）
  - 应急预案（受伤/迷路/天气突变的应对）
- **住宿触发**：多日骑行/徒步必须安排住宿（营地/民宿/客栈），单日往返不安排

**4. 落地方案准确性**
- **有交通工具的出行**（自驾、摩托）：不考虑公共交通，因为用户自带交通工具。重点放在路线规划、补给点、限行/禁摩区避开
- **无交通工具的出行**（骑行、徒步）：必须解决「怎么去起点」「终点怎么回」——徒步/骑行路段的前后接驳交通必须交代清楚
- **普通旅游**（公共交通模式）：按常规公共交通编排，飞机/高铁/客车/轮船按距离决策

**5. 天气规则**
- **无明确出行时间** → 不查天气
- **有明确时间且在 30 天以内** → 尽量查明途经地天气，提供恶劣天气备用方案：
  - **自驾**：主要提示行车安全，途经地可能发生的自然灾害（塌方/泥石流/暴雪封路）要防范
  - **摩托 / 骑行 / 徒步**：除安全提示外，还要强调——下雨视线不佳、路面湿滑、失温风险；防雨装备是必须的；天气不好时**强烈建议推迟或取消**，因为还有很多无法防范的风险
  - **普通旅游（城市/景点）**：天气不好时提供**室内备用方案**——去博物馆、商场、室内景点等，必须目的明确、方案精准，不能泛泛说「室内活动」

**6. 续航与补给规划（v0.1.16 新增）**
- 不同车型续航差异大，按 `references/vehicle_range.json` 查参数：
  - **纯电**：标称 500km → 实际 **325km**（×0.65 保守折扣），冬季/高速再降 15-30%
  - **插混**：纯电段标称 100km → 实际 **70km**（×0.70），混动段按燃油车算
  - **燃油轿车/SUV/MPV**：续航 650-700km，相对可靠
  - **摩托车**：200-400km（按排量），山区站间距可达 150km
  - **房车**：约 600km，油耗高，另需水/电/排污补给
- **规划纪律**：
  - 用 `real_world_range_km` 而非标称续航
  - 剩余续航 < `min_reserve_km` 时必须补给，不等亮灯
  - 单日计划里程 ≤ 实际续航 × 0.7（留 30% 余量）
  - 无人区/偏远路段加油站间隔可能 >150km，提前加满
  - 充电桩密度远低于加油站，偏远地区需提前确认
