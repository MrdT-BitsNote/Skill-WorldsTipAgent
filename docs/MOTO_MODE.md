### 1.11）摩旅模式（v0.1.1 新增 · v0.1.2 扩充）

> 摩托和汽车不是同一种出行。汽车问的是「堵不堵、油够不够、停哪儿」；
> 摩托问的是「这辆车、这个人、这条路，**合法吗**？跑得下来吗？」

**为什么单开一项，而不是复用自驾逻辑**

摩托有四项硬约束是汽车完全没有的：

| 约束 | 汽车 | 摩托 |
|---|---|---|
| 证件 | 有驾照就行 | **准驾车型必须匹配**——持 C1 骑摩托按无证驾驶处理 |
| 高速 | 随便上 | **逐省不同**，17 个省明文禁止，且各省规定不一致 |
| 城区 | 限行可绕 | **禁摩范围逐城不同**，闯进去可能直接扣车 |
| 续航 | 600-800km，服务区密布 | **200-400km，山区站间距可达 150km** |

用自驾逻辑处理摩托，会在上面四项上全部给出错误答案。所以单开一项。

**五项门禁（`scripts/moto_check.py`）**

引擎 `moto_card()` 输出五项灯位，与出境门禁卡同构（红/黄/绿/灰四灯 + 置顶渲染）：

| 灯位 | 检查内容 | 红灯条件 |
|---|---|---|
| `license` | 准驾车型（D/E/F）、行驶证、交强险 | 持非摩托准驾车型 / 无牌 / 无交强险 |
| `helmet` | 头盔（法定强制） | 未配备 |
| `highway` | 途经省份高速准入 | 仅当明确要走高速且该省禁止 |
| `ban` | 途经城市禁摩限摩 | 不设红灯（绕行可行） |
| `range` | 续航与加油半径 | 单日里程 > 满油续航 |

**灯色判定纪律（两条踩过坑的硬规则，不得回退）**

1. **「禁止上高速」≠「不能去」。** 摩托永远可以走国道。第一版把"四川禁摩上高速"判成红灯，导致「成都→康定」这种纯国道线路被判"行程不成立"——
   这是把**怎么去**错当成了**能不能去**。正确语义：禁止省 → 黄灯（改走国道，耗时 +40-80%），只有明确说"我要走高速"时才是红灯。

2. **「未查证」不得判红灯，也不得判绿灯。** 本库对查不到权威来源的城市（珠海、中山、银川、太原、呼和浩特、贵阳、拉萨）标 `stability: unknown`，
   一律给**灰灯**并写明"需自行核实"。
   拿一个没根据的结论去吓用户，和拿假绿灯放行，是同一种错误。

**数据与证据等级（`references/moto_rules.json`）**

- **31 个省级区域的高速准入**：13 allowed / 17 banned / 1 conditional（甘肃：法无明文但执法劝阻）
- **45 个城市的禁摩限摩**：含范围边界、限行时段、排量门槛；7 城标 unknown
- **证件合规链**：D/E/F 准驾定义、年检周期、异地通检、头盔强制依据、交强险
- **续航模型**：4 档排量续航基线 + 加油站实务（含 2023 新规：删除「推离 4.5 米」旧要求）

每条政策都带 **`evidence` 证据等级**，渲染时挂对应角标：

| 等级 | 含义 | 渲染 |
|---|---|---|
| `statute` | 有地方性法规/规章明文 | 不加角标（最可靠） |
| `practice` | 无明文，但以官方答复/执法实例为准 | 挂「（执法口径）」 |
| `third_party` | 仅第三方汇总，未核到官方原始出处 | 挂「（第三方来源·需核实）」 |

**线路库（`references/moto_routes.json`，25 条）**

三族分组，每条带季节窗口、里程、补给密度、高速依赖度、难度 1-5、caution、**绿荫等级（v0.1.2）**。本省线路覆盖信号见 `references/moto_coverage.json`（外部地图源「WorldsTip 摩旅地图库」已收录 31 省 1658 条，含 GPS 轨迹与全域可视化；本库仅收规划层子集）：

- **近郊跑山线** 12 条：妙峰山、红井路、皖南川藏线（桃岭）、四明山、南天荒坪、南昆山、幕阜山、蒲虹路；**＋湖南 4 条（太浮山、桃花源、黑麋峰、灰汤温泉，source: WorldsTip 摩旅地图库）**
- **长途穿越线** 8 条：G318 川藏南线、独库公路、滇藏线、丙察察、川西小环线、青海大环线；**＋湖南 2 条（壶瓶山、浏阳河溯源，source: WorldsTip 摩旅地图库）**
- **环线** 5 条：环青海湖、环海南岛、环太湖、环滇池+抚仙湖；**＋湖南 1 条（柳叶湖·太阳山，source: WorldsTip 摩旅地图库）**

> 线路库只写**稳定事实**（线路存在性、走向、地形、季节规律、补给密度定性）。
> **不写**具体加油站坐标、当年路况、实时封路——那三类必须出行前现查，写进库里等于埋雷。

**v0.1.2 三项扩充（对标调研结论，逐条落地）**

对标同类摩托车出行智能体、路书 AI Agent、行业数据池三家的调研结论，提炼出三个自家做得到却没做的点：

| # | 能力 | 学自 | 实现 |
|---|---|---|---|
| ① | **绿荫优先**：暴晒是摩托党大敌，选线阶段就该管 | 同类智能体 | `moto_routes.json` 每条线加 `shade`（高/中/低，基于地形性质定性判断）+ `shade_note` + `summer_window`；`suggest_routes(shade_min=, shade_first=)` 支持筛选与优先排序；`shade_advice()` 按等级给防护要求 |
| ② | **加油动作序列**：比续航数字更前置一步，直接给动作 | 同类智能体「高速前 2km 挑服务区」 | `check_range` 输出 `fuel_actions` 决策点序列：出发前加满 → 全程约 X km 处加油（附剩余油量与"保险站"判断）→ 抵达前不要等亮灯；高速场景的出发前文案按服务区口径给 |
| ③ | **出行前待核实清单**：库只写稳定事实，会过期的必须现查 | 行业数据池 + 社交平台 UGC | `scripts/moto_enrich.py`：`build_checklist()` 按行程算该查什么（政策/补给/路况/天气四类，按数据自身证据等级决定"必须查"还是"建议复核"）；`ingest_note()` 规定查回的东西怎么记 |

**数据增强通道的证据纪律（`moto_enrich.py`，不可让步）**

- 社媒/第三方来源（含社交平台）**永远** `evidence: third_party` + `stability: volatile`，无论多少人说一样的话；只有政府/交管原文才能标 statute。
- `ingest_note()` 四项必填（topic/content/source/date），缺一项直接抛错；`date` 不得晚于今天；超过 30 天自动挂 `stale_warning`。
- 坏笔记单列 errors 跳过，**不让一条坏数据毁掉整包**。
- 未收录城市（县级市等）在清单里是**必查项**——"未收录只代表没有数据，不代表不禁摩"。
- 合规边界：只检索公开信息，不做批量抓取，不保存原文，只保留「结论 + 来源 + 日期」三元组。

**用法**

```bash
python scripts/build_itinerary.py --from 成都 --to 康定 --days 3 --people 1 --style moto \
  --moto-cc 250 --moto-license E --moto-docs --moto-helmet --json > plan.json
python scripts/render_compact.py --plan plan.json --out 摩旅小册子.html
```

参数缺省即灰灯（**不猜**）：不给 `--moto-cc` 就不估算续航，不给 `--moto-license` 就不判定证件。
小册子会自动在门禁卡之后插入「摩旅可行性自检」板块；非摩旅行程不渲染该板块。

v0.1.2 新增参数：

| 参数 | 作用 |
|---|---|
| `--moto-shade-first` | 绿荫优先排序（只作用于已按目的地匹配出的候选，不打乱匹配结果） |
| `--moto-shade-min 高/中/低` | 最低绿荫等级过滤 |
| `--moto-prefer-highway` | 计划走高速：高速准入按红灯级判定，加油策略按服务区口径给 |
| `--moto-notes notes.json` | 传入检索回来的补充笔记（自动标 third_party + 时效天数） |

**册子是起点，不是终点（v0.1.2 · 学路书 AI Agent 的「生成后可对话迭代」）**

摩旅册子交付后，用户用自然语言提修改，直接改参数重跑即可，不要推倒重来：

| 用户这样说 | 改什么 |
|---|---|
| 「改成 5 天」「再多玩两天」 | `--days 5` |
| 「从武汉出发」 | `--from 武汉`（禁摩/高速清单按新路线自动重算） |
| 「想去林芝」 | `--to 康定 林芝`（多目的地） |
| 「两个人一起」 | `--people 2` |
| 「我的车是 500cc」 | `--moto-cc 500`（续航与加油序列自动重算） |
| 「满油能跑 300」 | `--moto-range 300` |
| 「我有 D 照」 | `--moto-license D` |
| 「要走高速」 | `--moto-prefer-highway`（高速准入转红灯级判定） |
| 「想走绿荫好的路」 | `--moto-shade-first` 或 `--moto-shade-min 高` |
| 「我查到 XX 地不禁摩」 | 写进 `--moto-notes` JSON（标 third_party + 日期） |
| 「预算 3000」 | `--budget 3000` |
| 「要更紧凑」 | `--no-fun` |

**纪律**：每次迭代只改用户提到的维度，其余沿用上一版参数；不要把一次小修改升级成重新调研。
