**封面速查卡**
| 项 | 内容 |
|---|---|
| 目的地 | 湖南省岳阳市（岳阳楼区 · 君山区） |
| 节奏 | 当天来回优先，住 1 夜更从容 |
| 核心诉求 | 爬山看日出 + 岳阳楼人文 + 洞庭湖 |
| 预算档 | 常规（人均 400–600 元，不含大交通） |
| 可信度 | 稳定项直出；天气 / 船班灰灯，出行前核验 |

**① 交通比选（六方式，按距离 / 时间 / 成本）**
| 方式 | 时长 | 估算票价 | 备注 |
|---|---|---|---|
| 高铁 | 约 2.5h（市中心到市中心） | 约 ¥165–210 | 准点，首选 |
| 自驾 | 约 3h | 油费 + 过路约 ¥220 + 停车 | 灵活，近郊首选 |
| 客车 | 约 3.5h | 约 ¥90–120 | 县域覆盖 |
| 飞机 | — | — | <800km 不纳入比选 |
> 结论：两人同行高铁 / 自驾二选一；高铁省心、自驾到点自由。

**② 逐日动线（按日出倒排）**
- **D1 下午**：抵达岳阳 → 岳阳楼（人文看点 + 洞庭湖落日）→ 晚餐地方风味。
- **D1 晚**：宿岳阳楼区，22:30 前休息。
- **D2 凌晨**：03:50 起床 → 04:30 上山（周边山径，按当日日出时刻倒推 60–90min）→ 看日出 → 下山早餐。
- **D2 上午**：洞庭湖湿地轻徒步 / 馆展（如开放）→ 午餐后返程。

**③ 住宿分房（两人）**
| 档 | 参考价 / 晚 | 说明 |
|---|---|---|
| 民宿 | 100–300 | 近岳阳楼，步行可达 |
| 经济连锁 | 200–350 | 停车方便 |
> 用户明确住宿安排 → 按用户来，不另推其他。

**④ 安全门禁（四灯）**
- 🟢 证件：身份证随身。
- 🟡 天气：日出日天气灰灯——出行前 1 天查官方预报；若雨雾则启动 Plan B（市区人文室内动线）。
- 🟢 交通：禁摩区 / 限行无；自驾注意景区停车。
- 🟢 健康：凌晨登山带头灯、保暖层；不独行夜路。

**⑤ 行前清单**
- 证件：身份证。
- 装备：头灯 / 手电、保暖层、防滑鞋、充电宝、水。
- 核验：日出时刻、D2 船班 / 景点开放、天气。
- Plan B（仅当天气明确变化）：岳阳楼 + 馆展 + 洞庭湖栈道室内 / 避雨动线。
