# 集中答疑（FAQ）

> 本页是 `worldstip-travel-planner` 的集中答疑入口，覆盖「能 / 不能做什么、版本号怎么读、怎么装、断网怎么办、各模式触发词、验收怎么跑」。其余架构与规范见 `docs/` 各文档。

## 1. 这个技能能做什么？
- 规划**国内**旅行，侧重短途与近程出行，产出**单文件 HTML 旅行指南小册子**（一键导出 PDF）。
- 三大支柱：① 国内全交通六方式比选；② 摩旅五项门禁（证件·头盔·高速·禁摩·续航）；③ 房车后勤（限高·牌照·补给·黑灰水·营地，不荐车型）。
- 数据可信度内核：易变信息强制核验、查不到即灰灯、绝不编造。

## 2. 这个技能不做什么？（不触发范围）
- 不代办票务 / 酒店机票预订；不做实时营业与导航绘制；不承接与旅行规划无关的请求。
- 不推荐具体车型（房车场景只给后勤基线，不替你选车）；不对易变价格 / 营位数 / 路况做确定语气直出，一律提示出行前核验。

## 3. 版本号怎么读？（双号体系）
- **内部开发版本 = 0.2.2**：本技能所有文档与 `SKILL.md` 的 `version` 统一以此为准，是迭代开发计数。
- **平台发布号（Skillhub `_meta.json` 的 `version`，如 1.0.0）**：是 Skillhub 平台的发布流水号，与内部开发版本相互单独、不冲突。
- 两者不是同一个计数体系，请勿混读；全包文档只以内部开发版本 0.2.2 为权威。

## 4. 怎么安装？（四种方式）
见 `INSTALL.md`：① SkillHub 技能页点「安装」（主位，推荐）；② WorkBuddy 分享页取技能包 / 专家包；③ 千问技能 Hub 点「加入我的 Agent」；④ 任意支持 `SKILL.md` 的平台放 `skills/` 目录，或纯手动挂载（`SKILL.md` 作提示词 + `references/` 作知识库）。

## 5. 断网 / 查不到数据怎么办？
- 分发包内置必要的离线数据，`--offline` 模式可断网跑通示例，不依赖外网。
- 运行时若某城市 / 景点无数据，按可信度内核如实降级：灰灯标注「未核验 / 查不到」，退回城市级建议，绝不编造名称、坐标或价格。
- 易变信息（票价、营位、路况、天气）一律提示出行前以官方渠道核验。

## 6. 各模式触发词
- **通用**：旅行规划、行程规划、旅游攻略、周末去哪玩、周边游、小册子。
- **玩法**：自驾游、徒步路线、爬山看日出、citywalk、亲子游、情侣游、美食游、演唱会攻略。
- **摩旅**：摩旅、骑摩托、机车、跑山、压弯、G318、川藏线、独库公路、禁摩、摩托车能不能上高速。
- **房车**：房车旅行、房车营地、露营地、加水、充电、黑水、灰水、排污、房车限高、C6 驾照、拖挂房车、床车。
- **不触发**：票务代订、酒店机票预订、导航绘制、与旅行无关的请求。

## 7. 质量门禁 / 验收怎么跑？
- 源码仓库内置回归套件：`tests/run_all_fused.py` 一键总入口（27 项行程回归 + 202 项数据引擎断言 + 融合专项断言，EXIT 0 即全 PASS）。
- 发布前 `tools/build_fused_pack.py --verify` 校验：包内文件与源码字节一致、根含 `SKILL.md`、固定时间戳。
- 标准扫描见 `_verify_v022.py`：12 组确定性检查（外链白名单、品牌名、受限词、危险执行特征、测试泄漏、本地路径、frontmatter、体积、二进制、地名全称、非景点隔离、省级归属、发布规范表述）。
- 验收结论（分数 / 编号 / 退出码）全部来自实跑，未实测项明确标注（见 `QC_REPORT.md` 与 `DoD.md`）。

## 8. 可选的 `moto-places` 扩展数据包是什么？
- 主包不内置景点级地点库（2514 条 / 32 省级单位 / 41 类，约 0.49MB）。需用时另装 `worldstip-travel-planner-ext-motoplaces` 扩展包，安装后落在 `references/` 目录。
- 安装后由 `scripts/places_query.py` 按需检索（默认回 8 条、只进结果不进上下文）；未安装时按退出码 `2` 降级契约处理（城市级建议 + 灰灯），不静默降级。

## 9. 数据来源与可信度
- 数据来自公开法规 / 行业口径与自有站点的结构化整理，每条带来源与时效标签。
- 三类稳定性：`stable`（法规 / 硬性事实，可直出）、`volatile`（价格 / 营位 / 路况 / 天气，提示核验）、`unknown`（查不到即灰灯）。
- 不承诺过审 / 上架；最终是否上线以平台通知为准。
