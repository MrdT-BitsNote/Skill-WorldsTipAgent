## 极限玩法库 · 自然美景专线（v0.0.3）

数据源 `references/extreme_sports.json`，两个专用画像 + 小册子专用板块：

**`extreme` 极限运动画像**（触发词：冲浪/跳伞/攀岩/蹦极/速降/骑马/射击/红牛玩法/极限）
- 8 类玩法卡片：每类含**国内基地清单、最佳季节、费用区间、装备、安全红线、天气停表**（如冲浪离岸流识别、跳伞持证查验、蹦极禁跳病史、野攀落石头盔）
- 预检阈值全库最严（降水 ≤2mm / 风 ≤25km/h）：**极限运动天气窗口即生命线，不达标直接改期，不存在硬上**
- 安全铁律：只选持证/备案场地、买含高风险运动条款的专项保险、告知书如实申报、装备检查参与确认
- 渲染时按用户 hint 自动匹配玩法（说「冲浪跳伞」只渲染冲浪+跳伞卡）

**`nature` 自然美景专线画像**（触发词：自然美景/风光线/秘境/日照金山/景观走廊）
- 三族景观线路库：**摩旅线**（川西小环线/怒江丙中洛/独库）、**自驾线**（伊犁河谷/G318/环青海湖）、**极端徒步线**（武功山穿越/雨崩/乌孙古道，硬核线路带标记）
- 每族强制配置**补给方案**（见站即补/垭口保暖/双电源）与**应急预案**（16 点前过垭口/高反下撤/三人同行/卫星通信）
- 规划原则：以景观走廊为骨架（晨雾光线→正午休整→黄昏金山），而非景点串联

**维护同步**：新增极限玩法需同步 `extreme_sports.json` + `MODE_TO_STYLE` 触发词 + `check_weather.py THRESHOLDS` + `render_booklet.py` 的 keywords 匹配表。

**新增方式需同步 4 处**：`STYLE_PROFILES`+`MODE_TO_STYLE` → `ACTIVE_PROFILES`（涉及里程）→ `check_weather.py` 的 `THRESHOLDS` → `render_booklet.py` 的 `_sec_packing/_sec_safety` 中 mode_key 映射。

## 实时数据源实测结论

| 数据源 | 状态 | 说明 |
|---|---|---|
| Open-Meteo 天气/地理编码 | ✅ 免授权 | 实时+16 天预报；地理编码**只接受 CN 结果**，四重校验防错配 |
| 12306 车站码表/车次号查询 | ✅/⚠️ | 码表免授权；车次查询仅支持车次号，**不支持 OD 查询** |
| 12306 票价 / 第三方票务接口 | ❌ 实时查询 | 需登录会话 / 已失效 / Forbidden —— **一律估算+文字引导官方渠道** |
| 交通查询文字指引 | ✅ 免授权 | `transit_links.py` 用 station_codes.json(3404站) 解析城市→站名→电报码，输出「请到官方渠道查询」文字提示；不生成任何可点击外链、不做站外引流 |
| 地图服务 API | ⚠️ 需授权 | 未配置授权返回空 |
| wttr.in | ✅ 备选 | 免授权天气降级方案 |
