**v0.1.35 变更（探索类型本地全量复现 · 缺陷修复 + 分层瘦身 + 版本单一真源）**

- **③ 多城市天数分配失衡**：原 `min(i, len(targets)-1)` 使最后一个城市吞掉所有剩余天数（7 天 3 城 → 1/1/5）。修复：按 `(i × 城市数) // 天数` 均分（→ 3/2/2）。
- **④ 当天来回仍输出住宿建议**：0 晚场景照常打印「房间数 1 间 / 建议大床房」，与「当天来回，无需住宿」自相矛盾。修复：`nights == 0` 时只输出「当天来回，无需住宿（0 晚）」。

## 打包与千问技能市场合规（v0.0.6）

本技能按千问技能市场 / 各 Agent 平台的 SKILL.md 规范制作，发布时遵守：

- **SKILL.md 必须位于包根目录**，zip 解压后第一层即 `SKILL.md`，不要套一层同名文件夹。
- **frontmatter 必备**：`name`（小写连字符）、`version`、`description`；`description` 内嵌触发词，是宿主唤起本技能的依据（已扩到口语/句式/跨语言，见上文）。
- **零依赖**：脚本纯 Python 标准库（无第三方包、无 API key），数据走相对路径 `references/`，跨平台跨 Agent 可直接跑。
- **资源随包**：`references/`、`scripts/`、`examples/` 全部内联，不依赖外部网络拉取。
- **多语言**：小册子正文/标题随用户语言生成，非中文页不残留中文、中文页不混未译专名。

**v0.1.29 变更（安全绿网合规整改 · 两轮驳回合并整改 + 交通逻辑修复）**：千问平台先后两轮驳回（第一轮「安全绿网」、第二轮「Skill 信息不可修改 + 安全绿网」），根因全部定位修复；并修复一处交通比选逻辑缺陷（短途误推高铁飞机）。

## 真实 API 实算配置（可选，v0.1.0）

本技能默认零依赖、纯估算；配置以下环境变量后自动升级为"真实 API 实算"，未配置或调用失败自动回落估算并标注「估算 ⓘ」，不影响主流程。

| 环境变量 | 数据源 | 作用 | 获取 |
| --- | --- | --- | --- |
| `MAP_CFG` | 地图服务 Web 服务 | `--compute map` 实算城际里程/驾车时长（交通比选"实算✓·地图服务"） | 地图服务开放平台 控制台 |
| `WEATHER_CFG` | 天气服务 | `fetch_weather.py` 优先调 天气服务 7 天预报（"实算✓·天气服务"），无则 Open-Meteo | 天气服务 开发者 |

典型用法：
```bash
export MAP_CFG=你的地图服务授权配置
export WEATHER_CFG=你的天气服务授权配置
python scripts/fetch_weather.py 成都 --days 7 --json > weather.json   # 天气服务优先/Open-Meteo 兜底
python scripts/build_itinerary.py --from 岳阳 --to 成都 --days 3 --style leisure --json > plan.json
python scripts/render_compact.py --plan plan.json --transit transit.json \
       --out book.html --title "岳阳→成都 3日骑行"
```
> 未配置时：天气走 Open-Meteo 实算（仍是真实数据，标「实算✓·Open-Meteo」），交通里程回落估算（标「估算 ⓘ」）。两者都不会让渲染失败。
