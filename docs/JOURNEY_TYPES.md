# 旅程类型全覆盖

> 本文件由 `SKILL.md` 分层拆分而来（v0.1.35），原始内容未删减。

## 旅程类型全覆盖（v0.0.5）

引擎 `build_itinerary.py` 对以下 8 类旅程均有回归验证：

| 旅程类型 | 天数 | 引擎处理 |
|---|---|---|
| 长旅程 | 5-10 天 | 多日画像 + 连写目的地自动拆分（`split_concat()` 最长匹配，如「丽江大理香格里拉」） |
| 中旅程 | 3-6 天 | 标准画像 + 逐日城市轮换 |
| 短旅程 | 1-3 天 | 短途圈调优默认值 |
| 到点（当日往返） | 1 天 | `nights = max(0, days-1)` = 0 晚，小册子渲染「当天来回，无需住宿」卡 |
| 随机旅程 | 任意 | `suggest_trip.py` 按出发地+偏好推荐候选目的地 |
| 极限旅程 | 任意 | `extreme` 画像 + 最严天气阈值（降水 ≤2mm / 风速 ≤25km/h）|
| 有预算 | 任意 | `--budget` → 小册子「预算核对」卡（预算内/超支 + 差额） |
| 无预算 | 任意 | 引擎经济画像自估，不出预算核对卡 |
| 演唱会旅程 | 1-N 天 | `concert` 画像：演出时刻为锚，到达时间决策树 + 演出日压轻量 + 住场馆近策略 + 散场交通 |

**v0.0.6 新增：演唱会（锚点事件型旅程）**。触发词「演唱会/音乐会/音乐节/livehouse/演出/巡演」→ `concert` 画像。与普通旅程的根本区别：演出时刻是全程唯一固定锚点，其余安排围绕它前后拼装——

- **到达时间决策树**：午前到 → 先吃喝玩再看（15:30 前转入演出节奏）；午后到 → 早晚饭后直奔场馆；傍晚到 → 演出优先一切后置
- **演出日定位**：1 天当天到当天看；2 天首日看（次日补玩返程）；3 天及以上演出日放中间，前后留缓冲
- **演出日压轻量**：当日最多 1 个景点，逐日动线自动插入「取周边→早晚饭→18:15 入场安检」锚点时间线（19:30 开演基准，按票面平移）
- **住哪策略**：只看一晚 → 住场馆 3km 内（散场 22:30 后打车溢价 30-80% 且排队 200+）；两晚以上还要逛吃 → 住市中心地铁沿线；郊区音乐节 → 无条件住场馆附近/接驳沿线
- **观演贴士**：检票（身份证+票截图+提前 60-90min）、禁带物品（专业相机/自拍杆/瓶装水/大包）、散场交通（地铁延时公告/步行 1 站再打车/官方接驳）
- **天数模板**：当天来回（仅 2h 交通圈+有末班车才排）/ 2 天 1 晚（最经典）/ 3 天 2 晚 / 4 天+（演出日居中）

数据源 `references/concert_playbook.json`，小册子渲染「🎤 演唱会之旅 · 锚点攻略」板块（仅 concert 画像）。

**v0.1.14 新增：散心模式（relax / 心情不好 / 随便去哪）**。触发词「心情不好想出去玩」「散心」「随便去哪」「不想上班想出去走走」「放空」「治愈」→ `relax` 画像。与普通旅程的根本区别：**只出目的地，不出行方式**——用户要的是「去哪玩」，不是「怎么去」。

- **输出纪律**：
  - ✅ 只渲染目的地报告：目的地有什么可玩的、当季看点、氛围描述、适合散心的理由
  - ✅ 可含住宿推荐（安静/治愈系民宿优先）+ 预算估算
  - ❌ **严禁出现交通方式**：不渲染 §02 怎么去、不出六方式比选表、不给「从 X 到 Y 怎么走」
  - ❌ **严禁出现紧凑行程**：不排逐日动线、不给时间锚点、不排「08:00 早餐 → 09:30 出发」
  - ✅ 可给「到了之后随便逛逛」的松散建议（如「湖边坐坐」「古镇发呆」「咖啡馆看书」）
- **目的地选择策略**：
  - 用户说天数 → 按天数匹配距离圈（3 天→短途圈 500km 内 / 5 天→中途圈 1000km 内 / 7 天+→长途）
  - 用户没说天数 → 默认推荐 3 天 2 晚（散心常见时长）
  - 优先推荐：安静/人少/自然/治愈系目的地（山水/海岛/古镇/乡村），避开网红打卡地/城市商圈
  - 季节匹配：当季最美的目的地（春→花海/秋→红叶/夏→避暑/冬→温泉）
- **渲染格式**：简化版小册子，只含 §01 路线总览（目的地介绍）+ §04 季节与气候 + §05 拍摄指南（可选）+ §06 住宿 + §07 预算 + §10 冷知识。跳过 §02 怎么去 + §03 逐日动线 + §08 行前清单 + §09 安全应急。

数据源复用 `destinations.json` + `seasons_climate.json` + `photography_guide.json`，小册子渲染「🌿 散心之旅 · 只去目的地」板块（仅 relax 画像）。

**v0.0.5 修复**：①当日往返住宿虚报（nights=1 → 0）；②连写目的地漏解析（新增最长匹配拆分）；③`--budget` 预算核对不渲染（键名对齐 `budget.user_budget`）。
