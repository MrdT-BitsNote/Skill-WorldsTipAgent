### 1.5）产品定位与取舍标准（v0.2.0，最高优先级纪律）

"指南 / 指导 / 指路"是伪命题——三者共用同一错误前提：**出行是为了获取信息**。真实需求是两件事：**别浪费**、**别翻车**。信息是最不值钱的一环（OTA 与 UGC 已把数量与新鲜度做到天花板）。

新增任何功能前，先过这张判定表（**不过就做进技能**）：

| 能力 | 判定 | 理由 |
|---|---|---|
| 交通时刻与怎么走 | **不做实时查询，只给官方渠道文字指引** | 12306/航司无开放 API；`transit_links.py` 解析城市→站名→电报码，输出「请到官方渠道查询」文字提示（不生成任何可点击外链、不做站外引流），票价以官方实时为准 |
| 配图与景点照片 | **不做** | `--no-images` 已落地，视觉靠排版 |
| 景点介绍与风土人情 | **降为背景** | 只服务「去不去」，不独立成章，不写观光介绍段 |
| 每日动线与取舍排序 | **核心** | 这就是「指导」本体 |
| 可行性体检闸门 | **核心** | 同类产品空白，出境下是硬门槛 |
| 预算与花费拆解 | **核心** | 直接决定「砍什么」 |
| 安全提醒与应急预案 | **升为闸门** | 从「板块」前置成「放行条件」 |

**自检问句**：这个功能是「帮用户做决定」还是「给用户加信息」？后者不做。

### 1.6）可信度内核（v0.2.0，所有出境能力的前置）

**零依赖 ≠ 离线可信。** 零依赖指运行时不依赖第三方包 / API key；调研仍走宿主 WebSearch / WebFetch（见「这个技能解决什么问题」下方纪律）。要放弃的是**「离线也给确定答案」**这个隐含承诺。

`references/stability.json` 把所有事实分三档，`scripts/credibility.py` 负责判定与渲染：

| 档位 | 处理 | 例子 |
|---|---|---|
| `stable` | 内置基线直出，不打扰 | 靠左行驶、不给小费、插头电压、不给女士小费 |
| `volatile` | **强制联网核验 + 打日期戳**；未核验必须挂「未核验」降级角标 | 签证政策、汇率、开放时间、票价、末班车、安全等级 |
| `unknown` | 输出「以××官网 / 使领馆当日信息为准」，**绝不猜** | 小众国具体材料、未收录目的地 |

### 1.7）地名判定与景点挂载（v0.2.1）

三个 references 撑起国内地名判定，`scripts/geo_lookup.py` 是唯一查询入口：

| 文件 | 覆盖 | 用途 |
|---|---|---|
| `geo_admin.json` | 34 省 / 361 市 / 3001 县（港澳台并入，用「中国××」表述） | `is_domestic()` 判定，**取代一切手写白名单** |
| `destination_links.json` | 249 景点 → 省市/气候/能力库/风险标签 | 票务、美食、气候的正确挂载依据 |
| `synthetic_sites.json` | 人造景点三分类（single/brand/guide）+ 决策钩子 | 重资产景区的排程与预算依据 |
| `geo_ambiguous.json` | 跨省同名实体（幕阜山8/五指山6/天柱山7 候选）+ 意图适配度 | **先查后问**的候选清单，避免静默猜错山 |

三条硬纪律：
- **只用索引，名单必然漏判**。中国有 3006 个县级行政区，手写几百个名字必然覆盖不到（芒市、霍尔果斯、婺源、阿尔山全都不在名单里 → 国内用户被误判出境 → 凭空弹出签证门禁卡）。
- **不用排除法**。宁可判非境内走灰灯「待查」，也绝不让境外地名被误判成境内（曾把「吉隆坡」砍尾成「吉隆」撞上西藏吉隆县、把「多伦多」撞上内蒙古多伦县——方向反了，境外用户会漏掉签证门禁）。
- **权威值优先于反查**。`SCENIC_ALIAS`（人工联网核验的完整归属）> 人造景点表 > `geo_ambiguous` 歧义标记 > 县级索引反查 > 大区兜底。反查只在前四者都落空时才用，且**唯一解才认，多解一律留 unresolved 等人工补**。
- **歧义优先于行政区命中**。geo_admin 里有「南岳区」（行政区），但用户说「南岳」几乎必然指山。歧义表命中即覆盖行政区记录——南岳山与南岳区相距不过 20km，多问一句的成本远低于排错程。

- 出境 5 个 JSON（`visa_rules` / `currency_tz` / `country_safety` / `local_customs` / `stability`）**不是权威答案库，是「基线缓存 + 核验清单」**。签证、汇率、免签名单一律 volatile。
- 册内「数据可信度台账」板块把未核验与待查项**诚实摊开**——不给可能过期的确定答案，这比沉默直出更负责。
- 该内核**反哺国内**：门票、开放时间、末班车、天气在国内同样是 volatile，此前以内置 JSON 权威口吻直出是同一类风险。
