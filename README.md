# WorldsTip旅行指南小册子（国内 + 出境双模式旅行规划技能）

> 分类：旅行　|　许可证：MIT　|　版本：v0.1.30　|　适用范围：中国大陆国内旅行（含港澳台）+ 出境旅行

规划**国内 + 出境**旅行，侧重短途与近程出行，输出
**单文件 HTML 旅行指南小册子**，一键导出 PDF 便于保存分享。

不是一段攻略文字，而是一本有季节方案、有逐日动线、有交通比选、
有人文看点、有行前清单、有安全提醒的小册子。

**产品定位**：WorldsTip 不告诉你有什么。它在有限预算、天数和体力下，
替你砍掉一半、排对顺序、并保证这趟不会翻车。

> **版本线（唯一权威）**：对外发布版本号 = 本地开发包版本号 = **0.1.30**（千问平台 slug `@user_gc9bq/worldstip-travel-planner`，地址 https://www.qianwenai.com/hub/skills/@user_gc9bq/worldstip-travel-planner ，上一版 0.1.0）。

## 核心能力

### 1. 四大交通族系全覆盖，六方式智能比选

| 族系 | 覆盖 |
|---|---|
| 公共交通 | 飞机、火车（高铁/普铁）、**客车**、**轮船** |
| 自驾行 | 摩托（摩旅）、汽车、房车 |
| 自行车骑行 | 城市骑游 / 环湖 / 长途骑线 |
| 徒步 | 景区步道 / 郊野线 / 爬山看日出 |

`plan_transit.py` 六方式比选，自动标注**近程圈（≤150km，当天来回）**
与**短途圈（≤300km，1-3 天）**。短途优先高铁，县域乡镇靠客车，
跨海岛与观光水域靠轮船，近郊自由行靠自驾/骑行。

**摩旅模式（v0.1.1 本版核心 · v0.1.2 扩充）**：摩托与汽车有四项完全不同构的硬约束，
沿用自驾逻辑会在这四项上全部答错——

| 约束 | 汽车 | 摩托 |
|---|---|---|
| 证件 | 有驾照就行 | **准驾车型必须匹配**（持 C1 骑摩托按无证驾驶处理） |
| 高速 | 随便上 | **逐省不同**：31 省中 17 省明文禁止 |
| 城区 | 限行可绕 | **逐城不同**：45 城禁摩限摩，闯进去可能直接扣车 |
| 续航 | 600-800km，服务区密布 | **200-400km**，山区站间距可达 150km |

`scripts/moto_check.py` 输出五项门禁灯（准驾车型证件 / 头盔 / 逐省高速准入 /
逐城禁摩 / 续航加油半径），数据来自 `references/moto_rules.json`
（每条带 `statute` / `practice` / `third_party` 证据等级，渲染时挂对应角标）
与 `references/moto_routes.json`（18 条线路：跑山 8 / 长途 6 / 环线 4）。

两条判定纪律（踩过坑，已由 465 项回归断言锁死）：

- **「禁止上高速」≠「不能去」**。摩托永远可以走国道。禁止省只给黄灯
  （改走国道，耗时 +40-80%），仅当你明确要走高速时才红灯——否则
  「成都→康定」这种纯国道线路会被误判成"行程不成立"。
- **「未查证」不得报红灯，也不得报绿灯**。未查到权威来源的城市一律灰灯
  ＋写明"需自行核实"。拿没根据的结论吓用户，与拿假绿灯放行，是同一种错误。

**v0.1.2 三项扩充**（对标同类摩托车出行智能体 / 路书 AI Agent / 行业数据池）：

- **绿荫优先**：18 条线路全部带 `shade` 绿荫等级（高/中/低，基于地形性质的
  定性判断）+ 夏季时段建议；`--moto-shade-first` / `--moto-shade-min` 让选线
  阶段就规避暴晒，而不是出发后靠防晒硬扛。
- **加油决策点动作序列**：续航校验不再只给"满油 X km"，而是给出
  「出发前加满 → 全程约 X km 处加油 → 抵达前不要等亮灯」的可执行序列，
  高速场景按服务区口径给（「高速前挑服务区」思路）。
- **出行前待核实清单 + UGC 数据增强**：`scripts/moto_enrich.py` 按行程算出
  该查什么（政策/补给/路况/天气，按证据等级定"必须查"或"建议复核"），
  检索回来的笔记（含社交平台 UGC）统一标 `third_party` + 日期，超 30 天自动告警。
  册子交付后可用自然语言提修改，按参数对照表改参重跑即可。

### 2. 跨省同名地理实体消歧（v0.3.0）

「幕阜山」是横跨湘鄂赣 160 公里的山脉，6 个候选看什么、怎么去完全不同。
单归属模型在此**结构性错误**——会静默给错答案，让人白跑一趟。

`geo_disambiguate.py` 先查后问：先列全部候选 + 差异维度，再让用户选。
用户已说县市名（「通山那边」）→ 直接锁定不再问；口误（「临湘那边的幕布山」）
→ 当场纠偏为平江县南江镇，不默默替换。

### 3. 出境：可行性门禁卡 + 4 维约束

**国外的可以做，但问到就必须答对。** `scripts/outbound_safety.py` 用 5 条防线把这句话变成硬约束（30 项断言，`--strict` 下任一失败退出码 1）：

1. **查不到 → unknown**：瓦坎达/苏联/锡兰/北塞浦路斯等必须走灰灯，绝不能给绿灯——绿灯等于回答「没问题」，对没收录的国家给绿灯就是编造。
2. **误映射探针**：迪拜→阿联酋（不是申根）、罗马→unknown、曼谷→泰国、第比利斯→格鲁吉亚。
3. **稳定性证据**：四张基线表都必须有 volatility 等级或 `_updated` 日期戳。
4. **结论可溯源**：表级 `_sources`（官方来源）+ `_updated` 日期，缺一半即失败。
5. **门禁四灯**：四灯必须齐备；签证 15 天办、3 天后出发必须判红灯并出拦停页（含行动项，不是只拦不教）。

v0.3.1 修复：互免签证名单 29 国未接入 `_pick_country`（问「格鲁吉亚要不要签证」只能答 unknown——数据在表里、代码没接上）；补齐三张表缺失的 `_sources`；修复 `render_booklet.py` 的 try 耦合缺陷（`gate_card` 缺失会连带关闭可信度内核）。

护照/签证/疫苗/保险四灯红黄绿，**strict 模式红灯直接输出拦停页，
不渲染行程**。准入 / 货币与时差 / 合规文化禁忌 / 领事与安全（12308）
四维约束，缺项走灰灯「待查」并写明去哪查，**绝不默认绿灯**。

### 4. 可信度内核

事实分 `stable / volatile / unknown` 三档：stable 可内置直出，
volatile 必须联网核验并打日期戳，unknown 明确标记待查、不猜。

### 5. 人造景点三分类（v0.2.1）

连锁品牌（方特/宋城/欢乐谷/长隆）同名多园，**先问「你指哪一园？」，
禁止给单一归属**——挂了会让用户买错园的票、走错城的高铁。

### 6. 季节与气候方案（小册子的灵魂板块）

六类气候区 × 四季数据库：当季看点、穿衣建议、气候风险。
结论绑定出行日期——10 月的大理能见度全年最佳，7 月的却是午后雷雨。

### 7. A5 紧凑卡册小册子 + 一键 PDF（默认渲染器 v0.1.14 起重做）

米白底 `#F7F4EE` + 深墨绿 `#0F4C3A` 主色、14px 紧凑、字段密集、**零图、零大留白**，
固定 10 章节（§01-§10：路线总览/怎么去/逐日动线/季节/拍摄/住宿/预算/清单/安全/冷知识）
+ TIP/WARN/NOTE 三色边线小贴士，Ctrl+P 即得 PDF。
旧版苹果风大留白渲染器 `render_booklet.py` 保留为备选（用户明确要时才调用）。
§10 内含条件子块「攻略核验 · 数据补充」（v0.1.28）：攻略研读沉淀的 ugc 数据按类分组渲染，
带来源徽章 + 核验日期，超期自动标「需出行前复核」，无数据整块不渲染。

## 使用方式

安装到支持 Skill 的 Agent，直接用自然语言提出需求：

- 「周末从岳阳去张家界爬山看日出，两天」
- 「近郊当天来回，帮我找个爬山的地方」
- 「下周骑摩托车跑山，帮我规划近程线路」
- 「一家三口高铁去长沙两日游」
- 「这周末不知道去哪，给点短途建议」
- 出境：「去日本要签证吗」「巴黎五天怎么玩」

## 明确的边界

不提供机票、火车票、船票的实时票价与余票，一律估算并引导官方渠道（12306）。
门票价格、开放时间、活动排期可能变动，请以官方当日公示为准。
经纬度为示意坐标，仅用于粗略距离与方向判断，**不得用于导航**。
