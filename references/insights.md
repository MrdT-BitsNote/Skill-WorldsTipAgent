# 长期记忆 / 生效中的规则（insights）

> 由 `growth_log.md` 蒸馏而来。**生效中的规则是默认行为**，新会话不必重新论证，直接执行。
> 蒸馏原则：只保留「换一批数据 / 换个技能仍成立」的不变量，一次性动作与本机路径不进本文件。

## 生效中的规则

| # | 规则 | 来源 | 违反后果 |
|---|---|---|---|
| R1 | **结构信号优先于名称启发式**。判断记录类型只认数据里的显式字段（如 `citySlug`），不用名称与父级名称的前缀 / 包含关系猜。 | #2 | 「北京 / 上海 / 吉林」被误判成省级汇总，明明有档案却谎报查不到 |
| R2 | **放宽匹配必须带归属约束**。子串 / 模糊兜底要么限定同省同辖区，要么在缺归属信息时列候选让用户选定，绝不静默取唯一命中并标成精确。 | #1 #2 | 「海南」静默挂到青海海南州，且 `match_level=normalized` 冒充精确匹配 |
| R3 | **改匹配规则后跑全量真实数据回归**，夹具全绿不算通过。夹具证明结构正确，不证明覆盖正确。 | #1 | 「鞍山 vs 马鞍山」类缺陷只在真实 386 名扫描中暴露 |
| R4 | **统计口径变更时禁止直接比大小**。要么换算成同一口径，要么做同输入 A/B 逐条对照并给未解释项归零。 | #2 | 把「386 去重 → 391 三元组」的口径差当成能力提升写进报告 |
| R5 | **文档数字必须标注口径与版本**，原型基线不得冒充最终结论；`SKILL.md` / `QC_REPORT.md` / `CHANGELOG.md` / 打包器版本号四处同步。 | #2 | 用户第一次打开就读到过期数字，报告 detail 与结论互相矛盾 |
| R6 | **写进 `description` 的触发词必须有路由回归断言**。 | #2 | 文档承诺「环青海湖住宿」能查，实际路由到错误意图 |
| R7 | **新增能力默认走开关，默认输出逐字节零回归**。 | #2 | 修一个问题顺手改坏三个老功能 |
| R8 | **自检器要有反向用例**：故意破坏一项，确认门禁真的会红；永远不触发的自检等于没有。 | #2 | 门禁全绿却完全没在检查 |
| R9 | **报告不写死哈希 / 时间戳**。会随产物变化的数值只由脚本实跑输出，避免自引用循环。 | #1 #2 | 报告里写 SHA，报告进包后 SHA 又变，自相矛盾 |
| R10 | **「全绿≠好用」**：每轮收尾必须打开真实产物用一次，或跑一次真实数据端到端。 | #1 #2 | 118 断言全绿仍藏 3 类静默错误 |
| R11 | **失败降级必须真降级**：无数据返回受控错误码，不返回空成功、不编造内容、不补白。 | #1 | 幻觉 POI / 假成功 |
| R12 | **人工确认表要标注复核触发条件**（数据更新后重跑扫描），并在输出里显式标精度损失。 | #1 | 别名表悄悄过期，降级冒充实测 |
| R13 | **字段类型靠全量实测枚举，不靠 schema 描述或第一眼样例**。`isinstance` 分布扫一遍再写取值函数；同一字段名在不同记录里可能是 list 也可能是 dict。 | #3 | `leisure/kids` 是 dict，按 list 判定把 33975 条 POI 谎报成 0 |
| R14 | **清洗规则按维度分别定义，不能全局套 `type` 闸门**。有些维度 `type` 全为空，硬套会把数据全删光；先统计各维度 type 的空值率与首段分布。 | #3 | `xiaocan/kids/malls` type 100% 为空 |
| R15 | **数据方自带的否决标记优先于评分排序**。「仅登记不推荐」「仅供登记」这类 `sub` 备注是硬闸门，评分再高也不能推给用户。 | #3 | 2024 条被标不推荐的苍蝇馆按高分进入推荐 |
| R16 | **字典型容器要区分「数据列表」与「元数据列表」**。`{subcats, list}` 里只有 `list` 是 POI，遍历所有 values 会把分类统计算成数据量。 | #3 | `leisure` 虚增约 4992 条，报告数字自相矛盾 |
| R17 | **静态快照 + 本地缓存必须配显式回源入口**。命中即返回、无 TTL/ETag/刷新参数，等于线上更新后永久读旧数据；`stats` 应报数据日期与缓存清单。 | #3 | 用户拿到过期 POI 却以为是最新的 |
| R18 | **修 bug 改默认输出时，用「差异路径类型归并 + 未解释项归零」代替「测试全绿」**。同时挑几条本该不变的路径做逐字节零回归。 | #3 | 282 条默认输出差异里混进未授权的行为变更 |

## 反模式库（踩过就不要再踩）

1. 用「名字像不像」替代「字段是不是」——R1。
2. 唯一子串命中就直接采信——R2。
3. 只跑夹具就宣布匹配率——R3。
4. 为了让数字好看换统计口径——R4。
5. 报告写「已知问题，后续优化」而不给数值 + 占比 + 位置——R5。
6. 在 `description` 里堆触发词却不测路由——R6。
7. 顺手改默认行为且声称「应该没影响」——R7。
8. 在报告里写死本包 SHA256——R9。
9. 看到字段名叫 `food` / `leisure` 就默认是数组——R13。
10. 给所有维度套同一个 `type` 清洗函数——R14。
11. 把数据方的「不推荐」备注当普通说明文字忽略——R15。
12. 遍历 dict 的所有 list 值来「数 POI」——R16。
13. 缓存命中就返回，不给用户刷新手段，也不在输出里报数据日期——R17。
14. 改了默认输出只跑一遍断言全绿就宣布安全——R18。

## 边界（本规则库的适用范围）

- 这些规则来自「两个静态中文地名数据集对齐 + 意图路由」这一类技能，迁移到别的领域时，
  **R1 / R2 / R7 / R8 / R9 / R10 / R11 / R17 / R18 通用**；R3 / R4 / R5 / R6 / R12 / R13 / R14 / R15 / R16 依赖「有可枚举的真实全量数据」这个前提，但其中的「先实测类型分布再写解析」思路对任何外部数据源都适用。
- 私有信息边界：本文件不记录客户名、私有路径、凭证与临时聊天细节；证据层只描述可复现的实测现象。
