# 数据参考索引

本目录对应 WorkBuddy 官方专家包样板中 `skills/<技能名>/references/` 的位置，用于存放**按需读取的索引说明**。与官方样板的品牌参考库一样，入口技能只声明口径，实际数据不随专家包复制。

## 数据来自哪里

- **唯一真源**：`worldstip-travel-planner` 独立技能包的 `references/` 目录（离线静态快照），当前对应技能版本 `0.2.273`。
- **不联网也能跑**：默认使用本地静态数据，联网只是可选增强；无缓存时按受控降级处理，不谎报成功。
- **本专家包没有数据副本**：运行时若找不到完整技能包的数据目录，按「未收录 / 需现场确认」降级，不自行补全，也不编造景点、票价或天气。

## 数据清单（按用途，非文件名）

| 用途 | 实测覆盖 | 说明 |
| --- | --- | --- |
| 目的地坐标与气候 | 393 城 | 用于距离估算与季节结论 |
| 必吃品类 | 26 个城市/区域键 | 只给品类 + 参考价，不含具体店名 |
| 景点 POI | 20 城 / 104 条 | 每条含玩法与到达方式，供逐日动线与出片清单使用 |
| 行政区划与车站代码 | 34 省级 / 361 市 / 3001 县、3405 站 | 用于同名地名消歧与交通比选 |
| 季节气候与交通规则 | 静态规则集 | 结论绑定出行日期 |
| 安全预案、摩旅路线、人文史 | 独立 sidecar | 按需加载，不常驻 |

省级行政区包含中国香港、中国澳门、中国台湾的规范名称；POI 与必吃层尚未收录港澳目的地明细，属已知缺口，命中时如实标注。

## 口径

1. **不编造**：票价、开放时间、天气、店名，不确定标「需现场确认」。
2. **不指店**：必吃只到品类与参考价。
3. **缺则标灰**：未覆盖城市显式降级，不用模板凑数。

两个数据集均为静态快照，**不含营业状态、排队、实时票价、天气**；跨省同名地名先列候选再让用户选定。

## 更新方式

数据更新只在独立技能包真源进行，并用 `doctor.py` 与 `tests/run_all.py` 复核；本专家包不维护第二份数据，避免在线 agent、落地页、本地包之间出现版本错位。
