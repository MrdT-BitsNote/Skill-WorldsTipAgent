# WorldsTip 旅行规划 · 专家调用入口

> **本文件是专家包内嵌技能的入口说明，不是技能正文副本。** 技能正文的唯一真源是 `worldstip-travel-planner` 独立技能包根目录的技能说明文件（当前 **v0.2.272**，恰好 500 行）；四个平台上传包都由该真源构建。本入口**不复制** POI、价格、天气等具体数据，避免两份口径出现版本错位。

## 1. 能力边界

| 能力 | 交付内容 | 硬约束 |
| --- | --- | --- |
| 怎么去 | 城市级交通比选（高铁 / 飞机 / 自驾）+ 每个景点到达方式 | 景点间路程算进动线，避免来回折返 |
| 必吃 · 必玩 | 必吃给品类 + 为什么值得 + 参考价；必玩给招牌景点与玩法 | **绝不指定具体店**；该推荐的一项不能少 |
| 逐日动线 | 每天几点出门、去哪、怎么串、车程与跨区次数、体力评级 | 跨天不重复排同一景点，高强度日后安排恢复日 |
| 季节与安全 | 结论绑定出行日期，按真实场景给提醒与应急预案 | 城市 walk 不列山区提醒；不写「注意安全」空话 |

## 2. 数据口径（三条红线）

1. **不编造**：景点、票价、开放时间、天气、店名，拿不准标「需现场确认」。
2. **不指店**：必吃只到品类与参考价，不写具体店名、摊位、餐厅。
3. **缺则标灰**：未覆盖城市在渲染层显式降级为「未收录」，不用「逛逛菜市场 / 温泉」这类模板凑数。

静态数据随**完整技能包**的 `references/` 目录分发，包含 393 城坐标气候、26 个城市/区域必吃品类、20 城 104 条 POI（每条含玩法与到达方式）、季节气候、行政区划与车站代码、摩旅路线、人文史 sidecar 等。**本专家包不复制数据副本**；数据不可用时按上述第 3 条降级，不自行补全。

跨省同名地名（幕阜山、临湘等）**先列候选再让用户选定**，不默认推断；非出行请求明确拒答。

## 3. 工作流程

1. **收口需求**：目的地、天数、人数、出行风格（休闲 / 特种兵 / 徒步 / 自驾 / 度假）、出发日期与季节。
2. **地名消歧**：抽取出发地与目的地，命中跨省同名时列候选，等用户锁定锚点再动笔。
3. **编排动线**：人本路由（最近邻串联、跨区封顶、跨天疲劳）生成逐日方案，并把景点间路程计入当天耗时。
4. **渲染交付**：A5 紧凑单文件 HTML 小册子（米白底 `#F7F4EE` + 深墨绿 `#0F4C3A` 主色），固定 11 章节，可一键保存 PDF；拍摄栏目按本次行程真实 POI 分题材输出，不写通用参数速查。

## 4. 输出契约

- 单文件 HTML，字段密集、零图、零大留白，自带 TIP / WARN / NOTE 三色边线小贴士。
- 票价 / 开放时间 / 坐标不确定时标「需现场确认」或「以官方渠道实时为准」。
- 必吃只到品类与参考价；必玩不缺项；未收录城市诚实标注。

## 5. 单一真源与修改纪律

| 对象 | 真源位置 | 本文件的关系 |
| --- | --- | --- |
| 版本号 | 独立技能包的版本真源文件 | 只引用当前版本 `0.2.272`，不改版本 |
| 技能正文 | 独立技能包根的技能说明文件（500 行） | 只摘要能力，不复制正文 |
| 静态数据 | 独立技能包 `references/` | 只描述口径，不复制数据 |
| 专家包结构 | 本专家包 `plugin.json` + `agents/` | 通过 Agent 的 `skills` 字段绑定本入口 |

**改能力时先改独立技能包真源，再重跑构建器同步四平台包**；本入口只在能力边界或触发条件变化时同步更新。版本真源、正文真源、数据真源三者始终只有一份，避免在线 agent、落地页、本地包版本错位。
